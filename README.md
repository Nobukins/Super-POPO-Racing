# Super POPO Racing

ピンクのひとつ目宇宙人「ポポ」が、宇宙船（UFO）に乗って地球の子どもたちとかけっこ勝負！
[Super POPO Land](https://github.com/Nobukins/Super-POPO-Land) シリーズの 8bit 風レースゲームです。
ブラウザだけで動き、ビルドやインストールは不要です。

## おはなし

地球に遊びに来ているポポは、日本の少年 **ユウタ** の家でいっしょに暮らしています。
ユウタに誘われて、子どもたちのかけっこ大会に **宇宙船で** 出場することに。
走ったり、自転車やスケボーに乗ったりしている子どもたちを尻目にスイスイ…のはずが、
**ねこ** や **おさる**、そしてポポをタコだと勘違いした **さかなやのおじさん** がじゃまをしてきます！
ユウタは沿道から応援しながら、自転車で追いかけてきてアイテムを届けてくれます。

## あそびかた

| 操作 | キーボード | タッチ | ゲームパッド |
| --- | --- | --- | --- |
| レーンをかえる | `↑` `↓` / `W` `S` | ▲ ▼ | 十字キー / スティック |
| ダッシュ（パワーを使う） | `→` / `D` | ▶ | 右 |
| ブレーキ | `←` / `A` | ◀ | 左 |
| ジャンプ | `Space` / `Z` | A | A / B |
| アイテムを使う | `X` / `Shift` | B | X / Y / RT |
| ポーズ | `Enter` / `Esc` / `P` | II | START |
| 音のオンオフ | `M` | 右上のボタン | – |

- **5 人でレース**。**3 位以内** でゴールすると次のステージが解放されます（全 5 ステージ）
- **こんぺいとう** を取るとダッシュの **パワー** がたまる。**やじるしパネル** で加速、**みずたまり** は減速
- ライバルの子どもにぶつかるとスピードダウン（ジャンプで飛びこえられる）

### じゃまもの

| じゃまもの | 動き | よけかた |
| --- | --- | --- |
| ねこ | ポポのレーンに飛び出してくる（ステージ 3 以降は途中で向き直る） | レーンをかえる / ジャンプ |
| おさる | 木の上からバナナの皮を投げてくる。地面のかげが落ちる場所 | かげのレーンを避ける / ジャンプ |
| さかなやのおじさん | 「タコだー！」と網を持って追いかけてくる（ステージ 5 はスクーター） | ダッシュで振り切る / 網をふる瞬間にジャンプ。つかまったらボタン連打 |

### ユウタのサポート

- コースの途中 3 か所（上のバーの 🎁 マーク）で、ユウタが自転車で追いかけてきてアイテムをくれる
  - **ラムネ**: ターボで加速。じゃまものもはね返す
  - **かさ**: 1 回だけじゃまを防ぐバリア
  - **にぼし**: 前方のねこ・おさる・おじさんがみんな夢中になってじゃまをやめる
  - 順位が低いほどラムネが出やすい。アイテムを持っているとパワー満タンになる
- 最下位が続くと「まけるな ポポ！」とパワーをくれる。おじさんにつかまると助けに来てくれる

`index.html?stage=3` のように URL で指定すると、そのステージから始められます。

## 起動方法

`index.html` をブラウザで開くだけで遊べます（`file://` のままで動作します）。

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

### オンライン公開（GitHub Pages）

`.github/workflows/pages.yml` が入っているので、`main` ブランチに push すると自動で公開されます。
初回だけ **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。

公開先: `https://<ユーザー名>.github.io/Super-POPO-Racing/`

### 1 ファイル版

```bash
python3 tools/build_single.py   # → dist/super-popo-racing.html
```

CSS・JS・アイコンをすべて埋め込んだ 1 つの HTML ができます。

## ファイル構成

```
index.html          画面・タッチボタン・あそびかた
style.css           見た目
js/sprites.js       ポポのドット絵データ（Super POPO Land と共通。tools/make_sprites.py で生成）
js/art.js           子どもたち・ユウタ・ねこ・さる・おじさん・UFO・背景・フォントをコードで生成
js/audio.js         効果音と BGM（WebAudio のチップチューン、すべてオリジナル曲）
js/input.js         キーボード / タッチ / ゲームパッド入力
js/stages.js        ステージデータとストーリー（コースの長さ・ライバルの速さ・じゃまものの数）
js/game.js          ゲーム本体（レース・AI・じゃまもの・アイテム・画面遷移・描画）
tools/              スプライト変換・1 ファイル版ビルド
assets/             ポポの元画像・アイコン
```

## ステージの調整

`js/stages.js` の各ステージで、難しさを変えられます。

```js
length: 12000,                                       // ゴールまでの距離 (10px = 1m)
kids: { mei: 172, riko: 176, haruto: 181, sota: 186 }, // ライバルの速さ (ポポは 200)
hazards: { cat: 7, monkey: 0, fish: 0 },             // じゃまものの数
puddle: 5, pad: 4, candy: 10,                        // みずたまり・ダッシュパネル・こんぺいとう列
catSmart: 0,                                         // 1 = ねこが途中でポポに向き直る
fishSpeed: 240,                                      // おじさんの最高速度
clearRank: 3,                                        // この順位以内でクリア
```

コースは各ステージで固定の乱数から作られるので、何度遊んでも同じ配置になります。
